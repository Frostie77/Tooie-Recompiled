# Redmi gameplay comparison

Install the APK whose filename ends in **GPU-Test.apk**. It appears as **Tooie GPU Test**
followed by its build identifier, alongside the previous test and public app.
It includes the startup correction previously tested on Redmi, corrected
widescreen visibility and the new Manual resolution choice. An FPS improvement
has not yet been measured on Redmi.

Choose **Graphics driver: System Default**. For the first comparison use:

| Setting | Value |
|---|---|
| Resolution | Manual |
| Resolution Scale | 1.00 (240p) |
| Downsampling Quality | Off |
| Framerate | Original |
| MS Anti-Aliasing | None |
| HUD Placement | Original |

Play the same short route with **Aspect Ratio: Original**, then repeat with
**Aspect Ratio: Expand**, leaving the other settings unchanged. Compare the
frame rate and responsiveness. If that works well, try Manual **2.00 (480p)**,
then **3.00 (720p)**.
The lower setting is useful for separating widescreen cost from resolution cost.

Please retain a settings screenshot and note the Android version, any displayed
FPS values for each mode, and whether the game closes and reopens successfully.
Describe an FPS change as both the starting and ending values when possible.
